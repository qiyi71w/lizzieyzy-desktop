# Function catalog extraction

The committed catalog is extracted from `wimi321/lizzieyzy-next` at `cb53acc55eda42c6c671b5f668cd3b597456bf07`, using its shaded jar (SHA-256 `739d77a2531c766375f617673c37f2de4e9760b7a9fc9dbbebde7ee156a4d6ee`). The extraction yields 360 functions in `FunctionCatalog.entries()` order, six categories, 76 sectioned settings targets, and eight maintained bundles. Search results use Java's ranking, including stable-ID ordering when browsing.

The committed file is then edited in place: Java's two interface-style switches become this product's three 外观模式 entries (`menu.appearanceMode*`), this product's 编辑面板布局… (`menu.editPanelLayout`, under 显示 > 面板, with its title, aliases and description in every bundle), 黑白胜率大字 (`menu.bigWinrateWindow`, the item after 显示 > 自动播放(Ctrl+A); its title is the later upstream's resource text, its aliases and description this product's, in every bundle) and 对局参数 (`menu.engineGameParameters`, under 棋局 after 暂停/继续引擎对局; its title is the later upstream's `EngineGameParameters.entry`, its aliases and description this product's, in every bundle) are added, 远程算力's 断开智子引擎 (`engine.disconnect-zhizi`, an `Action` under 设置 > 远程算力, its title `RemoteCompute.disconnectZhizi` from the Java string table and its aliases and description in every bundle) is added, the three later items of 显示 > 工具栏 > 顶部工具栏 > 自定义内容 (`menu.showPDAInMenu`, `menu.showWRNInMenu` and `menu.showSuggestionLimit`: 激进度, 广度 and 候选点上限; their titles are the later upstream's resource text, their aliases and descriptions this product's, in every bundle) are added, the later upstream's 棋盘坐标 settings row (`config.theme.coordinates`, in the theme section after `config.theme.winrate-font`, as the newer commit's `ConfigSettingTargets` has it; its title and description are that commit's resource texts, in every bundle) is added, and the eleven 详细工具栏 entries (`legacy.*` and `toolbar.detailed`) are left out, as this product leaves out that toolbar. Eight functions this product keeps inside a dialog or a child window are added after their owners' entries, each with this product's aliases and description in every bundle: 姓名旁胜率 (`board.name-winrates`, an `Action` after `menu.showNameInBoard`, titled `NameWinrates.title`), 开局广度 and 开局激进度 (`match.opening-wrn` and `match.opening-pda`, after `menu.newEngineGame`, titled by the Java `NewEngineGameDialog` labels), 分阶段 (`strength.phase-bounds`, after `menu.playerStrengthEstimate`, titled `PlayerStrengthEstimate.tab.phases`), 训练方式 (`humansl.training-mode`, after `game.ai-coach`, titled `HumanSlTraining.mode`) and the 野狐, 腾讯 and OGS 棋谱 windows' 打开棋谱后此窗口 (`fox.after-get`, `tencent.after-get` and `ogs.after-get`, after each window's entry, titled by the Java `FoxKifuDownload` and `TencentKifuDownload` labels); their Java titles come from the Java string table. Six entries whose Java dialogs this product folds into 综合设置 get that page as their `section` (Java extracts `null`): `menu.maxTreeWidth`, `menu.initialMaxScoreLead`, `menu.setReplayInterval`, `menu.minPlayoutsForNextMove` and `menu.setCandidatesDelay` get `"section":"engine"`, and `menu.frameFontSize` gets `"section":"theme"`. The English, Korean and Thai aliases of `menu.kataScolreLead` name the corrected 目数显示 items (see `CORRECTIONS` in `tools/extract_java_strings.py`). The bundle texts that `CORRECTIONS` also fixes carry the corrected text here too: `Config (Shift+X)` for Java's `Shif+X` (English and Thai `Menu.comprehensiveSettings` and `FunctionSearch.aliases.settings.general`), the proxy subtitle `ConfigDialog2.modern.proxy.subtitle` without "Java" in every bundle, and the Thai bundle's double-escaped `\:` and `\uXXXX` (`SetKataRules.lblScoringRule`, five `FunctionSearch.aliases.menu.*`) read as Java's author meant. It holds 367 entries; the bundles keep Java's whole `FunctionSearch.*` vocabulary.

From the repository root, set `JAVA_JAR` to that baseline jar and run with JDK 21:

```sh
javac -cp "$JAVA_JAR" -d /tmp/function-catalog tools/function_catalog/DumpFunctionCatalog.java
java -cp "/tmp/function-catalog:$JAVA_JAR" DumpFunctionCatalog "$JAVA_JAR" crates/lizzie-core/src/function_search/catalog.json
```

The generator reads the real catalog classes and uses `ResourceBundle.Control.getNoFallbackControl(FORMAT_PROPERTIES)`, retaining Java's resource-parent lookup and actual bundle locale. The JSON records the source commit and SHA-256 of the supplied jar. `tools/extract_java_strings.py` consumes these keys when regenerating the UI translations.

The UI translations come from the newer `6a5c8d1524f8bdfd9163162a38dcf64c23402a1b` (`next-2026-11-19.1`), while the entries above stay as extracted. Where that commit changed the text of a key the catalog's entries use, the catalog's bundles carry the newer text too, so that a function is found by the name the UI shows: `BottomToolbar.downloadWeight` (`Update weights`) and `BottomToolbar.gotomove` (`Go to`) in the base and English bundles, and `Menu.diagnosticsAndLogs` and `Menu.stopFullTrace` in the Japanese, Korean and Thai bundles, which the newer commit translates. `BottomToolbar.shareHistoryRemote`, the title of the withdrawn `share.public-history`, keeps its extracted text; the newer commit deleted it.

One entry comes from the newer commit itself: OGS棋谱 (`menu.ogsKifu`, under 同步, after `menu.tencentKifu`, as that commit's `FunctionCatalog.kifuEntry("ogs")` builds it). Its `Menu.ogsKifu`, `FunctionSearch.description.menu.ogsKifu` and `FunctionSearch.aliases.menu.ogsKifu` are copied into every bundle from that commit's `DisplayStrings` files, with Java's parent lookup.
